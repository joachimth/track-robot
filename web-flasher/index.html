🤖 Track Robot Firmware Flasher

Flash firmware to your ESP32-C5 directly from your browser

Before You Start

  • ✅ Use Chrome or Edge browser (Firefox/Safari not supported)
  • ✅ Connect ESP32-C5 via USB cable (data cable, not charge-only)
  • ✅ Install USB drivers if needed (CP210x or CH340)
  • ⚠️ All existing data on the ESP32 will be erased

Flash Firmware

Installation Steps:

  1. Select firmware version above
  2. Click "Connect and Install"
  3. Select your ESP32 serial port
  4. Wait for installation to complete (~2 minutes)
  5. View logs and reset your device

Hardware Requirements

  • MCU: ESP32-C5 (Waveshare dev board recommended)
  • Motors: 2x DC motors with BTS7960 H-bridge drivers
  • Power: 12V battery (Milwaukee M12 or similar)
  • Controller: PS4 controller (BLE) or use Serial/HTTP

Alternative Flashing Methods

Using esptool.py (Command Line) 
pip install esptool
esptool.py --chip esp32c5 --port /dev/ttyUSB0 \
  write_flash 0x0 merged-firmware-vX.Y.Z.bin
Using ESP-IDF 
cd firmware
idf.py set-target esp32c5
idf.py build flash monitor

Troubleshooting

❌ "No port selected" or can't connect
  • Install USB drivers (CP210x or CH340 depending on your board)
  • Try a different USB cable (must be data cable)
  • Check that no other program is using the serial port
  • Try a different USB port
❌ "Failed to connect" or timeout errors
  • Hold BOOT button on ESP32 while connecting
  • Power cycle the ESP32 (unplug and replug)
  • Check that you selected the correct port
❌ "Browser not supported"
  • Use Google Chrome or Microsoft Edge (latest version)
  • Enable "Experimental Web Platform features" in chrome://flags
  • Firefox and Safari do not support Web Serial API
